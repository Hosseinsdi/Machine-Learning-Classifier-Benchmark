# Machine-Learning-Classifier-Benchmark
This Python project compares three machine learning classifiers—Gaussian Naive Bayes, KNN, and ID3 Decision Tree on the Banknote Authentication dataset. It evaluates their accuracy, applies basic preprocessing and pruning, and generates result files and comparison plots.

This project is a simple machine learning comparison program written in Python. It loads the Banknote Authentication dataset, splits it into training, validation, and test sets, and then evaluates three classifiers: Gaussian Naive Bayes, K-Nearest Neighbors (KNN), and a custom Decision Tree based on the ID3 algorithm. The KNN model uses normalized features, while Naive Bayes and the Decision Tree are trained on the original data. The Decision Tree also includes a basic pruning step using the validation set. After training, the program compares the accuracy of all models on the test set, saves the results in a text file, and generates two plots: one for model accuracy comparison and another for learning curves. The output files include results.txt, model_accuracy_comparison.png, and learning_curves.png. This project demonstrates core concepts in machine learning, classification, model evaluation, and data visualization using NumPy, Pandas, Matplotlib, and SciPy.
